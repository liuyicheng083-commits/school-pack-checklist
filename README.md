# 🎒 开学物品检查清单

一个用于开学前检查未携带物品的离线网页应用。双击即可使用，进度自动保存在浏览器本地。

## 功能

- 📄 8 大分类、63 件预设物品（证件资料 / 电子产品 / 衣物 / 洗漱用品 / 宿舍用品 / 学习用品 / 药品 / 日常用品）
- ✅ 勾选已带物品，顶部实时显示进度和剩余未带件数
- 🔍 「只显示未带」一键筛选 + 关键词搜索
- ➕ 新建自己的分类，添加自定义物品
- 🔗 每个物品可附带自定义链接（购物/参考网址），点击直接打开
- ✎ 编辑物品名称与链接
- 💾 所有改动自动保存在浏览器本地，刷新不丢失

## 使用方式

直接双击 `index.html` 用浏览器打开即可，手机浏览器同样可用。

## 在线预览

将本仓库部署到 GitHub Pages 后，可通过 `https://<用户名>.github.io/school-pack-checklist/` 直接访问。

> 提示：由于是纯静态单文件应用，数据只保存在各设备浏览器本地，不会上传到服务器。
